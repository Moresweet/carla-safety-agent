# 原始采集数据校验

在 Collect Data 选择已保存的数据集，点击“检查六视角、深度、点云与原始输入”。后台独立进程检查文件，不访问 CARLA、不切图、不启动模型。每个桥接服务一次最多运行一个扫描，最长 300 秒；超时为“未完成”，而非通过。录制中的数据及旧单视角格式拒绝提交。

检查内容包括帧号和时间严格递增、索引路径与样本身份、清单样本数、归档场景引用、原始 NPZ 输入覆盖、六视角 PNG 与保存 BGRA 的逐像素一致性、深度有限米值、标定尺寸、XYZI 点云和 BEV 图像可读性。有外参的传感器检查刚体变换与逆矩阵；历史缺失外参不会计作已验证。

状态分为未检查、运行中、通过、失败和未完成。结果保存于 `.runtime/dataset-quality`，重启后仍可查看。报告带时间、退出码、日志、扫描开始时的 manifest SHA-256；扫描期间 manifest 改变时结果为未完成。

报告是一次扫描的历史证据，不是原始数据的完整不可变快照。文件可被外部工具修改，未实现所有原始文件的内容哈希快照或并发写锁；修改后必须重新检查。该检查不证明驾驶安全、检测标注准确、无遮挡或模型输入在物理意义上完全正确。采样间隔异常不等于传感器丢帧。原始文件合格也不意味着采集进程清理成功。

离线验证：`PYTHONPATH=src <模型环境Python> tools/validate_capture_dataset.py <数据集目录>`。不要使用 `-O`，校验器会拒绝禁用断言的运行方式。隔离坏数据回归：`PYTHONPATH=src <模型环境Python> tools/regression_capture_quality.py`，不修改已有数据。

## 逐传感器帧身份检查（2026-09-10）

扫描逐样本核对 frame.json 与索引的帧号、时间戳，要求 synchronized=true、missing=[]；六路 RGB、六路深度、LiDAR、BEV_RGB 均须有同帧来源记录，实际模型输入还须在 sensor_frames 中逐项出现。缺少这些证据的历史样本不会获报同步通过，仍可按原有能力播放。此检查不补造外参，不证明传感器物理真值或驾驶安全。
