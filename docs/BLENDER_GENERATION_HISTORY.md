# Blender 生成与失败记录

Asset Workshop 分别展示持久化生成记录和 Unreal 导入记录。
生成任务启动前持久记录 preparing/generating，退出且结果清单明确 ok 后记录 exported。
运行异常、超时、非零退出或结果清单缺失/损坏记录 needs_attention，保留任务文件和报告。
已导出不表示已经导入 Unreal 或在 CARLA 中生成。

桥接中断可能留下 preparing/generating；界面明确表示尚未确认结束，不自动重试。
初始记录写入失败不启动 Blender；但可能留下空任务目录。磁盘失败、强杀及引擎操作
不构成跨进程原子事务，报告不保证能覆盖所有断电情形。

非法非有限尺寸/粗糙度、非法RGBA和超限纹理在创建任务前拒绝。
原有有限尺寸0.01..1000、粗糙度0..1截断行为保留。
创建入口不再发送重贴纹理栏的source_path；新生成开始即清除旧结果，失败后不可误导入/生成旧资产。
三个操作使用同步引用锁阻止同一次双击重入；不承诺跨浏览器或重新点击的服务端幂等性。
