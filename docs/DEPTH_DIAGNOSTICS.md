# 回放深度交叉检查

Collect Data → 选择已保存数据 → RGB 点云投影 → 点云深度交叉检查。

逐点用保存的深度相机自身 K 与外参重新投影 LiDAR，不能简单按 RGB 尺寸缩放。接口要求 RGB、深度、LiDAR 的原始帧记录一致，且帧号/时间与回放索引一致；缺少标定或旧格式无法确认同步时明确拒绝。

按针孔模型的相机前向深度与落点像素深度比较：容差为 max(0.5 米, 深度×2%)，容差内黄色、表面后方红色、表面前方蓝色；零值、非有限值、接近1000米上限或深度视野外为灰色未知。计数覆盖 RGB 视野内所有点，绘制最多5000点，并保留原点索引。辅助深度可与 RGB 不同分辨率或位姿。

这是诊断工具，不输出精确遮挡真值：低分辨率边缘、针孔近似、未建模镜头畸变、透明材质和不同传感器的采样差异都可能造成偏差；红色仅表示比该深度像素更远，不能直接当作模型检测错误。物体框仍只做几何投影，未进行深度遮挡裁剪。

CARLA 的深度编码和传感器参数参考[官方传感器文档](https://carla.readthedocs.io/en/0.9.16/ref_sensors/#depth-camera)。本地深度相机通过 DepthEffectMaterial_GLSL 产生编码，当前诊断采用 optical-forward-Z 约定；不宣称已覆盖所有镜头配置或所有版本。
