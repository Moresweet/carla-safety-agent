- 根因实测：CARLA 原生 `get_world()` 在本机连接失败时持有 Python GIL。独立进程设置 2 秒超时后，本应在 0.1 秒醒来的 Python 线程实际延迟 2.0016 秒；因此模拟器离线时也会阻塞同进程数据接口。页面定时轮询未等待前一请求，又放大了积压。
