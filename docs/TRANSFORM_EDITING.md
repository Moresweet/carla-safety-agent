# 对象位置草稿与旧请求保护

Scene Object Manager 的位置编辑把实时目录值与未应用草稿分开。后台刷新不会覆盖草稿；清空数值不等于输入0；应用失败保留输入与错误，不自动重试。放弃草稿读取最新目录，切换对象或离开页面会丢弃当前未应用草稿。环境对象位置只读。

网页通过`POST /objects/update-reviewed`提交坐标及首次输入时观察到的`expected`：世界episode字符串、actor ID、type ID、位置和yaw。目录未提供身份时禁止编辑。世界身份变化会重建编辑组件，避免沿用另一世界的草稿。

后端先验证格式，再在持有本机仿真锁或闭环唯一tick所有者的命令边界验证当前对象。世界/ID/类型不一致或位置偏移超过0.02米、yaw环绕差超过0.05度时拒绝，提示放弃后重新读取；阈值用于容纳目录毫米取整，不是定位精度保证。正在运动的对象可能经常触发拒绝，不能自动把旧草稿覆盖到其新位置。

这是乐观并发检查，不是世界事务或鉴权机制：无保证阻止未受控原生客户端在检查后继续修改世界，也不锁定物理演算。旧`/objects/update`保留给既有内部流程；复制、删除、聚焦、其他编辑入口不据此宣称全部获得此保护。对象类型与episode不是完整资产内容指纹。后续新增的空闲纳管对象[位置历史](POSITION_HISTORY.md)使用该入口记录位置撤销/重做，两项功能边界分开。
