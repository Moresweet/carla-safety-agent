# 自然语言局部修订

Generate Scene 编译后可输入明确的中文字段修改，预览逐字段差异，再采纳新计划。
采纳不运行仿真；旧模型确认会清除，规则或模型执行仍需单独确认。

例：`自车速度改为5 m/s；天气改为晴天；光照改为白天；运行时长改为1秒；其余保持不变`。
支持自车/单个对手速度、触发距离、运行时长、随机种子、雨量、雾浓度、晴天/小雨/大雨、白天/夜间、Town 地图及已有金属管组数量。
速度必须带单位。地图安装和模型兼容性仍在启动时检查，生成地图不能由该入口改成普通地图。

这是一组有界、确定性的中文指令，不是任意自然语言建模或通用 LLM 编辑器。
未知子句、重复冲突字段、越界值或没有实际变化均拒绝整次修改，不部分采纳。
预览期间执行入口锁定；取消保留原计划。错误不会触发自动执行或自动重试。

`POST /scenario/revise` 只接受本地内容寻址计划路径、准确 SHA-256 和 instruction。
父归档原始字节保留，新归档记录父 SHA、指令与差异，修订深度最多32。
原描述用于溯源；执行以采纳后的 JSON 和 SHA 为准。重新编译原描述会重新产生基线计划。
此接口不访问 CARLA、不生成 Blender 资产、不切换地图。
