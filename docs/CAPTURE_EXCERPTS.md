# 诊断窗口归档

数据与回放页选择已保存录制，暂停并定位帧，在“保存诊断片段并导出 ZIP”中设置前后秒数，勾选确认。后台复制选中样本、校验原始输入并生成 ZIP；完成后可下载或打开独立片段回放。这不会启动模型、切换地图或改写原录制。

## 边界

- 只接受统一格式 0.2 的 `saved`、`saved_limit`、`saved_recovered`；中断录制先走恢复流程。不递归截取片段。
- 必须选中实际保存帧，按时间戳选取，不插帧。前后各 0–10 秒，最多 256 样本 / 4 GiB；超出源录制边界明确截断。复制前要求额外空间至少为源文件总量两倍加 1 GiB。
- 要求工作台无活动执行、记录的原进程身份已退出；复制开始和发布前检查。此流程不声称锁住所有外部进程。
- 复制原始 PNG、米值深度、点云、输入 NPZ、帧元数据及标定。源样本字节不改写，模型原始输入和空间预测契约保留。预测时间步仍未验证，不计算 ADE/FDE。
- 碰撞按所选时间范围保留；编辑命令按其原始事件映射保留，包括稀疏采样间隔内映射到选中帧的命令。原事件完整文档、原 manifest/index 在 ZIP 的 `source-metadata/` 中保留；这里不是完整数据集目录。
- 新数据集状态 `saved_excerpt`，明确是子集；源任务起止时间、跳帧等累计计数保留，不可冒充片段统计或完整任务成功。现有训练划分不自动接纳此状态。
- 原始数据校验在隔离 Python 进程执行，超时/失败不发布。源文件前后 SHA-256 比较仅覆盖参与归档的文件，不认证未选择的源帧。下载再次核对 ZIP 哈希，HTTP 分块传输，不把整个 ZIP 装进桥接内存。
- 显式请求 ID 防止重复提交；桥接重启后的未完成任务显示 `needs_attention`，不自动重试。失败副本与原件保留，需要人工检查；不提供断电原子事务或跨机自动安装承诺。

命令行入口（本机模型 Python 环境）：

```bash
PYTHONPATH=src /home/moresweet/Data/e2e/miniconda3/envs/uniad-cu128/bin/python tools/export_capture_excerpt.py CAPTURE_ID --frame FRAME --before 0.1 --after 0.1 --confirm-copy
```

任务报告：`.runtime/dataset-excerpts/<request-id>.json`；ZIP 及审计证据保留在同名子目录。验证后的回放目录发布到 `.runtime/generated-scenarios/excerpt-<id>`。这些运行数据不提交 Git。
