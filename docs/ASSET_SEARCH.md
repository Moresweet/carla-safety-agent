# 完整资产目录检索

Create Objects 改为在全部可用 Blueprint ID 上先过滤，再分页返回，每页48项。
原先只取前200项再在前端搜索，可能永久遗漏目录尾部的生成资产。
支持名称子串，以及明确的中文关键词：车辆/汽车、行人、道具、生成资产、护栏、路锥、长椅、垃圾桶、特斯拉、奥迪、自行车。多个词空格分隔，各词共同匹配。

它不是语义或外观检索，不从名称推断颜色、尺寸或真实形状，也不制造不存在的资产。
Generated 分类来自本机注册表；运行中的目录来自 worker 快照，可能不包含生成资产。
生成资产没有本入口支持的真实缩略图，显示“缩略图未验证”，不请求不支持的缩略图接口。
悬停卡片可查看完整 ID。选中资产后仍须显式拖放，搜索本身不触发创建。
原生缩略图沿用既有缓存/渲染链，不能将未缓存缩略图渲染泛称为零世界操作。

HTTP GET /catalog/blueprints 支持 q、kind、offset、limit；limit为1..200，offset为0..100000。
返回total、offset、limit、has_more和blueprints。非法参数400，不返回伪成功空列表。
前端200ms合并输入、10秒读取超时、取消旧请求且忽略迟到结果；重复拖放同步互斥。
创建成功后聚焦失败单独提示，不把已创建对象说成创建失败。
